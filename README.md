A one-line entry for the make.fun "The Most Honest Outage Line" bounty:
a Python program that writes a single status page line — the honest
message an AI agent publishes while a total outage is under way — to
`/output/entry.txt`.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to change where
`entry.txt` lands).
